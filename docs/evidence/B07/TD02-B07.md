# TD02 — Discarded samples and restarts

## Scenario

Repeated, out-of-order and previous-session samples are discarded without renewing the validity; a simulator restart and a Node-RED restart both leave the state in UNKNOWN. There is no step back and no unknown session is accepted.

## Code version

B03, merged as `9fb2e0f` (#93); tested on its branch on 18 and 19 Nov. Dashboard restart check: B04, `<merge commit of #97>`.

## Configuration

As in TD01, plus `mosquitto_sub -h localhost -t 'telemetry/#' -F '%I %p'` and the "discarded" debug node of the Node-RED editor.

## Steps

1. Press Duplicate and Out of order on `BUS-DEMO-01`.
2. Replay old samples between live ones, and publish a sample of another session.
3. Press Restart on a simulator.
4. Run `docker restart nodered_service`.

## Notes and limitations

Node-RED keeps its state in memory only: after a restart nothing is restored and the old sessions no longer match the expected ones.
