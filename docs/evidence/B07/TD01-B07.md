# TD01 — Limit combinations on both ramp nodes

## Scenario

The four combinations of the two limit switches, on both simulated nodes (`ramp-node-01` of `BUS-DEMO-01` and `ramp-node-02` of `BUS-DEMO-02`), give the position and quality of the proposal, and the dashboard shows each vehicle apart from the other.

| Stowed | Deployed | Position | Quality |
| --- | --- | --- | --- |
| true | false | STOWED | VALID |
| false | true | DEPLOYED | VALID |
| false | false | INTERMEDIATE | VALID |
| true | true | UNKNOWN | INVALID |

## Code version

- Simulators and ingestion: B03, merged as `9fb2e0f` (#93). Tested on its branch on 18 and 19 Nov.
- Dashboard: B04, `<merge commit of #97>`. Tested on its branch on 21 Nov.

## Configuration

`docker compose up -d`; Mosquitto 2.1.2, Node-RED 4.1.3 with Dashboard 2.0 1.29.0. Simulators publish every 5 s; the ingestion marks STALE after 15 s. Terminal: `mosquitto_sub -h localhost -t 'vehicles/+/ramp/state' -F '%I %p'`.

## Steps

1. In the dashboard select `BUS-DEMO-01`. Press Normal (stowed goes through intermediate to deployed), Incomplete, Contradiction and Normal again.
2. Check that `BUS-DEMO-02` did not change.
3. Select `BUS-DEMO-02` and repeat.

## Result

| Combination | BUS-DEMO-01 | BUS-DEMO-02 |
| --- | --- | --- |
| STOWED · VALID | Steady state | Steady state, and again at 01:20:35 |
| INTERMEDIATE · VALID | 01:21:38 and 01:21:50 | 01:20:27 and 01:20:54 |
| DEPLOYED · VALID | 01:21:41 | 01:20:30 |
| UNKNOWN · INVALID | 01:21:44 | 01:20:39 |

While one vehicle changed, the other stayed STOWED · VALID. In the dashboard, with Contradiction on `BUS-DEMO-01`, the lines read `UNKNOWN · INVALID` for 01 and `STOWED · VALID` for 02.
