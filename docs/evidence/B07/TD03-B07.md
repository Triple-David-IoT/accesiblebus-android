# TD03 — Simulator stopped, Node-RED stopped, old retained projection

## Scenario

Two different limits: after 15 s without a sample Node-RED publishes STALE; after 10 s without a new projection the HMI goes to UNKNOWN. A retained projection alone never gives VALID on the HMI.

## Code version

B03 `9fb2e0f` (#93) and HMI detector B13 `1c3cacc` (#95); both tested on their branches on 19 Nov.

## Configuration

As in TD01. HMI on the Android emulator against the same broker, watching `vehicles/BUS-DEMO-01/ramp/state`.

## Steps

1. Press Cut / resume on `BUS-DEMO-01`, wait for STALE, then press it again.
2. During STALE, replay the last sample every 5 s.
3. With the HMI showing "Flow active", run `docker stop nodered_service`.
4. With Node-RED stopped, close and reopen the HMI.
5. Run `docker start nodered_service`.
