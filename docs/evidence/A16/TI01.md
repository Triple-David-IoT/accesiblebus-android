# TI01: passenger and driver, from the stop list to the announcement

## Scenario

The whole passenger path against the laboratory: the app downloads the stops, the passenger
asks for assistance, the driver's HMI acknowledges it, the driver accepts, and the passenger is
told according to the phone context (C09): text and vibration with the phone in hand, voice with
the phone covered.

## Configuration

- **Code:** `develop` at `857482d`, debug build against the laboratory:
  `./gradlew assembleDebug -PuseSampleApi=false -PapiBaseUrl=http://127.0.0.1:8000/ -PmqttBroker=tcp://127.0.0.1:11883`.
- **Laboratory:** API, PostgreSQL, Mosquitto and Node-RED on the VM. Demo reset before the run
  (trip `0a90dc48`).
- **Passenger:** Aquaris C, Android 8.1, real light and proximity sensors, voice mode AUTO
  (the default). API and broker over USB (`adb reverse` and an SSH tunnel to the VM); Wi-Fi only
  for the CRTM download.
- **Driver:** HMI on a Pixel 8 emulator, same build and same tunnel.
- Run by A on 22 Nov 2026. B and C were not present; C reviews the sheet.

## Observations

- The announcements of C09 are in English, while the passenger screens are in Spanish.
- The phone's time zone is Europe/London and its clock is one hour ahead, so "Registrada a las
  16:49" does not match the clock in the status bar. The app converts the server time correctly;
  the phone is misconfigured.
