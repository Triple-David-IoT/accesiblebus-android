# TM06: a decision made while the app is offline is shown and announced once

Pixel 8 emulator with the debug build pointing at the laboratory API and broker:

```bash
./gradlew installDebug -PuseSampleApi=false -PapiBaseUrl=http://192.168.1.172:8000/ -PmqttBroker=tcp://10.0.2.2:11883
```

The laboratory broker listens on the VM loopback, so it was reached through an SSH tunnel
(`ssh -N -L 11883:127.0.0.1:11883`). The HMI is not built yet (B09), so the driver used curl
with the `demo-conductor-1` token. Until the AnnouncementCoordinator (C) exists, each
announcement is a line in logcat with the tag `Announcement`.

## Steps and results

1. Demo reset; the passenger requests assistance at stop 459. Tracking shows
   "Avisos en vivo activos" and the request PENDING.
2. Airplane mode on (13:17:07). About 5 s later the app shows "Sin avisos en vivo"
   (`01-offline.png`).
3. The driver accepts with curl (200). The app still shows PENDING: it received nothing.
4. Airplane mode off (13:17:31). Without touching the app, about 10 s later MQTTastic
   reconnected, the repository ran `/sync` and Tracking shows "Aceptada por el conductor"
   with live notices back on (`02-reconnected.png`).
5. With the app connected, the driver completes with curl at 13:18:11. Tracking shows
   "Completada" about 1 s later, from the MQTT event alone (`03-live-event.png`). This also
   shows that the subscription came back after the reconnection.
6. "Actualizar", then the app is stopped and opened again.

Announcements in logcat for the whole run:

```text
12:17:40 I Announcement: announce DecisionEvent(requestId=c47058cb-..., version=2, state=ACCEPTED, reason=null)
12:18:10 I Announcement: announce DecisionEvent(requestId=c47058cb-..., version=3, state=COMPLETED, reason=null)
```

One per decision. Neither the manual `/sync`, nor the restart, nor any late copy of the
events produced a second one. (Logcat uses UTC; the times in the steps are local time.)

## Unit tests

`RepositoryEventsTest` covers the same rules with a fake feed: an event delivered twice, the
same decision by `/sync` and by another copy, an older event arriving late, the reconnection
`/sync`, announcements kept across a restart, receipts, trip progress, and an event of an
unknown trip that brings the new trip with `/sync`.
