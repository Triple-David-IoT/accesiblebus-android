# C07 Validation Test — Preferences Persistence and MQTT Reconnection

## Test Objective

Verify that the C07 preferences and network configuration are applied correctly, that saved values remain available after restarting the application, and that the MQTT broker connection continues to work after changing the configuration.

## Test Procedure

1. **Open the application**
   - Launch the Accessible Mobility application.
   - Navigate to the profile/preferences screen.

2. **Check the current configuration**
   - Review the voice preference, vibration, and high-contrast settings.
   - Review the API URL and MQTT broker settings (host, port, and token).

3. **Change and save preferences**
   - Modify one or more preferences.
   - Save the changes.
   - Reopen the preferences screen and verify that the selected values are still displayed.

4. **Change the broker configuration**
   - Enter the intended broker host, port, and token.
   - Save the configuration.
   - Allow the application to apply the updated connection settings.

5. **Verify the broker connection**
   - Check that the application connects using the updated broker configuration.
   - Verify that the app can continue its MQTT-related operation, such as receiving stop-arrival updates or request-status updates, where applicable.

6. **Verify persistence after restarting**
   - Close and reopen the application.
   - Return to the preferences screen.
   - Confirm that the saved preferences and connection settings are retained.
   - Verify that the broker connection is established using the saved configuration.

## Expected Result

- The preferences selected by the user remain saved and are shown when the preferences screen is opened again.
- The API and MQTT configuration values remain available after restarting the application.
- After changing and saving the broker configuration, the application connects using the updated settings.
- MQTT-dependent functionality continues to operate with the selected broker configuration.

## Validation Result

**C07 validation: Successful**, provided the checks above were observed during the test.

This test focuses on verifying the application behavior from the user's perspective: settings are saved and retained, and the MQTT broker connection remains functional after configuration changes.
